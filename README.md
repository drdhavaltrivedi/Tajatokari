# 🥗 Tajatokari — 100% Organic Farm-Fresh Ready-to-Cook Vegetables

> **Tajatokari** is a premium D2C e-commerce web application for ready-to-cook, 100% organic, chemical-free chopped vegetables in Ahmedabad, Gujarat.

---

## 🌟 Key Features

### 1. 🌾 100% Organic & Chemical-Free Guarantee
- **Farm Direct Sourcing**: Sourced directly from certified organic partner farms in Gujarat.
- **Zero Chemicals**: 100% pesticide-free, fertilizer-free, and wax-free produce.
- **3-Step Ozone Purified Wash**: Triple-washed in ozone-purified water and precision-chopped using stainless steel food-grade equipment.

### 2. 📦 3 Family Organic Packages
- **Starter Package (₹199)**: Serves 2–3 Persons *(Includes 4 essential daily chopped veggies)*.
- **Grow Package (₹499)**: Serves 4–5 Persons *(Includes 6 daily chopped veggies + 1 Chef Gravy Base)*.
- **Premium Package (₹799)**: Serves 7–8 Persons *(Includes 8 daily chopped veggies, Organic Paneer Cubes & 2 Gravy Bases)*.

### 3. 🧺 "Build Your Own Organic Basket" (Custom Combo Creator)
- Select your preferred box size (**4 Veggies @ ₹249**, **6 Veggies @ ₹369**, or **8 Veggies @ ₹479**).
- Interactive veggie picker grid with live slot counter and visual item chips.
- One-click **"Add Custom Basket to Cart"** functionality.

### 4. 🍳 10-Minute Meal Prep Guides & Recipe Bundles
- Pre-configured meal bundles for popular Indian dishes:
  - **Organic Pav Bhaji Prep (₹189)**
  - **Paneer Butter Masala Bundle (₹249)**
  - **Veg Stir-Fry / Fried Rice (₹169)**
  - **Gujarati Mix Veg Curry (₹199)**
- One-tap **"Add All Recipe Ingredients to Basket"**.
- Product catalog badges displaying *"Ideal for Sabzi, Gravies & Stir-Fry"*.

### 5. ⏱️ Interactive Time & Waste Savings Calculator
- Calculates monthly kitchen prep hours saved and organic peel waste eliminated based on weekly meal frequency.

### 6. 📱 Seamless Mobile UX & WhatsApp Order System
- **100% Mobile Responsive**: Touch targets $\ge 44\text{px}$, sticky mobile basket bar, and iOS input auto-zoom fix.
- **Local Storage Address Fill**: Saves user delivery details for instant 1-click reorders.
- **Coupon System**: Discount code `TAJA10` for 10% OFF.
- **Direct WhatsApp Checkout**: Auto-generates itemized order details, delivery slot preference, and payment choice (UPI / COD).

## 🚀 How to Run Locally

Since Tajatokari is built using pure Vanilla Web technologies with zero runtime framework dependencies:

1. **Direct Browser**: Double-click `index.html` to launch directly in any browser (Chrome, Safari, Edge, Firefox).
2. **VS Code Live Server**: Open the workspace directory in VS Code and click **"Go Live"**.
3. **Local HTTP Server** (Optional):
   ```bash
   npx http-server -p 8080
   ```
   Then navigate to `http://localhost:8080`.
